Works

Research & experiments

weir

a typed shell-scripting language

Shell scripting without the footguns: the whole script is type-checked before anything runs - commands resolved against PATH, no word-splitting surprises, CLI parsers generated from type declarations. A single binary, no runtime dependencies.

fsc-host

F# scripts as plugins

Extend F# apps with F# scripts - load strongly-typed plugins at runtime.

rooz

work in containers

Reproducible, disposable dev environments in containers. Written in Rust.

yzl

F# DSL for YAML

Generate YAML from typed F# instead of templating strings.
